# Chores

## Vision
A shared household task list for one family, so that chores don't get forgotten.

## Problem
Chores were agreed at the dinner table and forgotten by the weekend. Nobody knew what was still open.

## Target users
- Family members (2 adults, 2 teenagers): add tasks, see what is open, mark tasks as done. Almost always on their phones, sometimes on the family laptop.

## Core value
Everyone sees what is still open and what is late.

## Non-goals
- No user accounts, no assignment of tasks to persons, no notifications (for now).

## Glossary
- Task: a title (1–100 characters), an optional due date, open or done.
- Due date: the calendar day a task should be done by (no time of day).
- Working day: Monday to Friday. Public holidays are not taken into account (see 002).
- Overdue: see 002 R1.
