# 001 – Task list MVP

- Type: MVP
- Status: Built

## Stories (abridged)
- S1 Meister creates a task with title, customer, optional address, optional due date and assigns it to one employee.
- S2 Employees see their open tasks, sorted by due date.
- S3 Employees mark tasks as done; the Meister sees the status of all tasks.
- S4 Meister can reassign or edit any task.
