Before I can make the taskboard video I need the macOS premium voices. None are installed on this Mac, and the standard or "Enhanced" voices make the narration sound robotic, so I won't use them.

Please install them:

System Settings → Accessibility → Spoken Content → click **ⓘ** next to *System voice* → **Voice** → search for **Premium** → download all of the English premium voices.
