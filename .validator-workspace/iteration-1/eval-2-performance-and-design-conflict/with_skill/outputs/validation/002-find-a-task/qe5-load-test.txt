Note for the coming rounds: this measurement was taken on the match rule that is
built today (prefix, case-sensitive), which returns far fewer rows than the
required rule (F1). The unfiltered list request in the same run returns all 500
tasks, which is the largest response the corrected rule could ever produce, and
it stayed at p95 5.22 ms, so the threshold has headroom. QE5 must still be
re-measured after F1 is fixed.
